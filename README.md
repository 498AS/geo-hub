# GEO Hub · Zoopa + 498A

Hub interno con dashboard de todos los planes, manuales, knowledge bases y recursos del proyecto de visibilidad de marca en LLMs.

→ **Web:** https://498as.github.io/geo-hub/

Marcado como `noindex, nofollow`. Pensado para uso interno del equipo Zoopa + 498A.

- Stack tecnológico (GEOradar + SAM + LEO + Zoopa MCN + producción inhouse)
- Servicio GEO-Video (plan estratégico + manual operativo + manual cliente)
- YouTube knowledge base
- Reddit (planes MOOTOOM + Zoopa)
- Quora (canal complementario)
- Infraestructura: vault Obsidian, memoria persistente, content-factory, bundle ZIP
- Próximos pasos accionables
